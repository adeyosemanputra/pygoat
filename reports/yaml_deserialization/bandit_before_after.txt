SUMMARY OF CHANGES
==================

1. Replaced yaml.load(file.stream, Loader=yaml.Loader) with yaml.safe_load(file.stream)
   - yaml.safe_load() only permits basic YAML types (dict, list, strings, numbers)
   - Prevents instantiation of arbitrary Python objects
   - Raises yaml.YAMLError on dangerous tags like !!python/object

2. Added type validation
   if not isinstance(data, (dict, list)):
       flash("Invalid YAML format: expected a dictionary or list")
   - Ensures parsed YAML matches expected structure
   - Provides user feedback on validation failure

3. Improved error handling
   - Separated yaml.YAMLError from generic Exception
   - More specific error messages for different failure modes
   - Better logging for debugging
