Welcome to PyGoat

PyGoat is an educational platform designed to teach web application security through practical OWASP Top 10 exercises. Use the sidebar to browse all modules, or choose an option below to get started.

1. Understand the Flaw

Read explanations of why vulnerabilities occur, how they can be exploited, and the impact they have on web systems.

2. Practice in the Lab

Test your knowledge against real, interactive vulnerable endpoints built directly in Python and Django.

3. Apply the Fix

Review the underlying source code to see where mistakes were made and learn how to implement secure coding patterns.
