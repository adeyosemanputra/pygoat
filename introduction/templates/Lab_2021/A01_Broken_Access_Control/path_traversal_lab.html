A01:2025 - Path Traversal

What is Path Traversal?

Path traversal (directory traversal) happens when an application builds a file path from user input and does not keep the result inside the intended directory. An attacker can then read files they should not see.

This sits under A01:2025 – Broken Access Control because the application fails to enforce the file-access boundary.

How the lab is exploited

  • Relative escape: ../secret/admin_credentials.txt walks out of the uploads folder.
  • Absolute path: /etc/passwd works too. os.path.join drops the uploads base when the second part is absolute, so the check that only looks for .. misses it.

Correct fix

Resolve the path with os.path.realpath, then require os.path.commonpath([base, filepath]) == base. A startswith prefix check is not enough: it would allow a sibling directory such as /app/uploads_backup.
